# Who The FUCK
**Vibe Coding** warning  
A simple tool that lets you use `wtf <port>` to find out what the hell is occupying that port.

## Installation

## Usage
```bash
Who the FUCK is using this port?

Usage: wtf [OPTIONS] <PORT>

Arguments:
  <PORT>

Options:
  -v, --verbose
  -a, --all
  -h, --help     Print help
  -V, --version  Print version
```
